# Clínica Dental Sonrisa Saludable

Proyecto JavaFX + SQLite listo para IntelliJ Community 2025 (JDK 17).

## Ejecutar
1. Abrir proyecto en IntelliJ (File -> Open) en la carpeta raíz.
2. Crear una configuración Maven: Command line = clean javafx:run, o ejecutar en terminal `mvn clean javafx:run`.
3. Si prefieres, crear una Run Configuration Maven llamada 'Ejecutar JavaFX' y usar el botón Run ▶️.

El proyecto inicializa la base de datos en `db/odontologia.db`.
